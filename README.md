# CSharp-Blackjack

A simple console-based Blackjack game written in C#. This project is my demonstration of my basic knowlege of programming concepts, including methods and game logic in C#.
This is to make a game of blackjack that the user or a algorithm can play specifcally to test the Martingale system which I came up with by myself seperately with a little 
observation and later learned that it had already been thought of.

## Features

- Play a classic game of Blackjack in the console.
- Simple and clear command-line interface.
- Handles card dealing, player actions (hit, stand), and basic game rules.
- Keeps track of player and dealer hands and scores.
- Allows an alorithm based upon the Martingale system to play tons of games for the user.
